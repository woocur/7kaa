# 세븐킹덤즈 고해상도 시제품 - Windows 다운로드

**[7kaa-hires-win64.zip 내려받기](https://github.com/woocur/7kaa/raw/download/7kaa-hires-win64.zip)** (44MB)

1. 압축을 풀고 `7kaa.exe`를 실행합니다.
2. SmartScreen 경고가 뜨면 "추가 정보" → "실행" (서명 없는 테스트 빌드).
3. 게임이 시작되면 모니터 해상도 그대로 그립니다. Alt+Enter로 창모드 전환.

소스 코드는 [hires 브랜치](https://github.com/woocur/7kaa/tree/hires)에 있습니다. 라이선스: GPL v2.
